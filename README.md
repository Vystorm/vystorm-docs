# Vystorm developer docs

API references for building on the free Vystorm plugins and the Vystorm client mod. The files are self-contained, so you can hand them to an AI coding assistant as context.

| File | Covers |
|---|---|
| [core/API.md](core/API.md) | **Vystorm Core** (Paper/Purpur 26.2 plugin): localization, settings, menus, dialogs, shared database, web pages, client-mod integration, and more. Build against the Core jar (`compileOnly`). |
| [client/API.md](client/API.md) | **Vystorm Client** (Fabric mod, Minecraft 26.2): in-game web overlay and native HUD elements. Covers the protocol, element schema, trust model and server-side integration, both with and without Vystorm Core. |

The plugins and the mod are free downloads (MIT license). This repository contains documentation only.
